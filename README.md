# 🧮 CALCULADORA POO – JAVA SWING

## 📌 Descrição do Projeto

Projeto desenvolvido para a disciplina de Programação Orientada a Objetos (POO), utilizando a linguagem Java e a biblioteca Swing para criação de uma interface gráfica.

A calculadora permite realizar operações matemáticas básicas e potência, por meio de botões interativos.

## 💻 Requisitos

Para executar o projeto, é necessário:

- Eclipse IDE instalado.
- JDK instalado (Java Development Kit).
- Projeto configurado como Java Project.

## ⚙️ Como importar e executar no Eclipse IDE

### 1. Criar o projeto

1. Abra o Eclipse IDE.
2. Acesse **File → New → Java Project**.
3. Digite o nome `POO-Calculadora`.
4. Selecione uma versão do JDK instalada.
5. Clique em **Finish**.

### 2. Criar a classe Java

1. Abra a pasta `src`.
2. Clique com o botão direito em `src`.
3. Selecione **New → Class**.
4. No campo Name, digite `CalculadoraSimples`.
5. Marque a opção para criar o método `public static void main(String[] args)`, se desejar.
6. Clique em **Finish**.
7. Substitua o conteúdo da classe pelo código disponibilizado neste repositório.

**Importante:** o nome do arquivo e da classe devem ser exatamente `CalculadoraSimples`.

### 3. Executar a calculadora

1. Abra o arquivo `CalculadoraSimples.java`.
2. Clique com o botão direito no editor.
3. Selecione **Run As → Java Application**.
4. A janela da calculadora será aberta.

Também é possível executar pelo botão verde **Run (▶)** na barra superior do Eclipse.
